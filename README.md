Personal portfolio site for **Fisco Maulana Ikhwan** — showcasing projects, technical skills, and professional experience as a Junior Software Engineer.

## 🚀 Live Demo

🔗 **https://web-profile-sigma-ten.vercel.app**

## ✨ Features

- **Project showcase** — featured projects with live demo links
- **Tech stack** — categorized skills with badges
- **Experience timeline** — internships & organizational roles
- **Certifications** — BNSP, IBM SkillsBuild
- **Responsive** — mobile, tablet, desktop
- **Dark mode ready**

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS |
| Deployment | Vercel |
| Content | Markdown / MDX |

## ⚡ Quick Start

```bash
git clone https://github.com/feastco/web-profile.git
cd web-profile
npm install
npm run dev
# Open http://localhost:3000
```
